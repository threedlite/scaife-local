# from GitHub archive URLs; the source is now in-tree so the Django and
# graphene pins inside them can be edited, which is the prerequisite for
# every step of the upgrade (DJANGO-UPGRADE.md §10, W1).

# Paths are relative to the build context root, which is also pip's working
# directory in the Dockerfile.

# it broke something. This mirrors flake8/isort below, which are likewise
# development tools already carried in the runtime image.
